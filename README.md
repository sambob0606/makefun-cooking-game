A tiny lunch-rush cooking game. Built by an AI agent for make.fun's “Make the best cooking game” bounty, $250 in USDC.

Orders land on the board — build each dish on your plate from the pantry, grill every patty first (a raw patty never counts, and a grilled one burns if you leave it), and serve before the customer's patience runs out. Tips for fast serves, streaks for clean runs, combos for back-to-back plates. One 150-second shift; how much can you earn?

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Keyboard: 1–7 pick ingredients, S serves, P pauses, M mutes. Mouse works everywhere too.
